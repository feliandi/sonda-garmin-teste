# Mapa offline para relógio Garmin

Arquivos baixados por um app pessoal de mapa offline para o Garmin Venu Sq 2 Music.

- `mapas/`: pacotes do mapa, em formato binário próprio codificado em Base64.
- Arquivos `j*.json` e `t*.txt` na raiz: bytes aleatórios usados para medir o download.

## Fontes dos dados

- Base da Europa: [Natural Earth](https://www.naturalearthdata.com/), domínio público.
- Cidades: © colaboradores do [OpenStreetMap](https://www.openstreetmap.org/copyright), disponível sob a licença Open Database License (ODbL).
